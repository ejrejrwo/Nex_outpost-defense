## 입력과 화면

배포본에서 HUD 시작 콜백, 숫자키 1/2/3, D 이동, Esc 정지·재개, 화면↔월드 좌표 변환, F 보호구, E 취소 환불, 전투 중 2/3번 전환과 Space 회피를 검사했습니다. 입력 검사에서는 상황을 만들기 위한 임시 상태를 사용하며, 검사 후 상태를 완전히 초기화하고 별도의 정상 완주를 시작합니다.

입력은 Unreal의 키 이벤트와 HUD 콜백을 주입한 방식입니다. OS 마우스 클릭을 재현한 검증은 아닙니다. Windows 창 조작 도구의 앱 접근 승인이 만료되어 실제 OS 키보드·마우스 플레이는 별도로 확인하지 못했습니다. 자동 실행에는 `-nosound`를 사용해 실제 청취 평가도 포함하지 않습니다.

## 재현

```powershell
.\Tools\build.ps1 -Action Test
.\Tools\build.ps1 -Action Package
.\Tools\validate_package.ps1 -Mode hard -Rank 2
.\Tools\validate_package.ps1 -Mode practice -Rank 2
```

`build.ps1`는 새 자동화 보고서의 UTC 시각과 결과를 검사하므로 엔진 종료 코드가 0이어도 테스트 실패를 성공으로 처리하지 않습니다. `validate_package.ps1`는 배포본의 종료 코드·새 보고서·완주·처치 수·채굴량·입력 검사를 확인하며 실패 시 비정상 종료합니다. 초기 화면 확인에는 `-ForceRes`로 캡처 크기를 고정합니다.
